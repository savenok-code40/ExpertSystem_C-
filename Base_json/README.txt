ИНСТРУКЦИЯ ПО ЗАПУСКУ ЭКСПЕРТНОЙ СИСТЕМЫ "ExpertBase"

1. Распакуйте все файлы из архива в отдельную папку.
2. Запустите файл ExpertBase.exe.
3. В верхнем меню выберите: "Файл" -> "Загрузить".
4. Выберите файл базы знаний "vent_base.json" (идет в комплекте).
5. Основные возможности:
   - Вкладка "Факты", "Правила", "Рекомендации": создание, просмотр и редактирование фактов, правил и рекомендаций.
   - Вкладка "Работа":
     * Выберите целевой факт в выпадающем списке и нажмите "Проверить цель".
     * Нажмите "Пересчитать правила" для актуализации всей рабочей памяти без проверки цели.
     * Рекомендации обновляются по нажатию кнопки "Пересчитать" или "Обновить рекомендации" на основе фактов в РП.

ВАЖНО: Для корректной работы не удаляйте папку "runtimes" и .dll файлы из каталога программы.
